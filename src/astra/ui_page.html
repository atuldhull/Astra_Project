Live checks: fix loss / satellite drop in flight (jamming-like), position re-appearing impossibly far after an outage (spoofing-like), receiver accuracy worse than 5 m (degraded). A spoof that keeps a healthy fix (e.g. the spoof-jump example) is not visible to these receiver checks: add a Shield calibration made from at least 0.5 h of this drone's normal flights (astra shield calibrate), or run Analyse on the log afterwards, which also uses the IMU. On real field attacks the receiver checks caught 3/3 within ~10–20 s; telling spoofing from jamming is less reliable. See the docs for limits.
